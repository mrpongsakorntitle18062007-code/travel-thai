# 🇹🇭 TravelThai - คู่มือท่องเที่ยวไทยอัจฉริยะ (AI-Powered Complete Web Platform)

> โครงงานพัฒนาเว็บไซต์ส่งอาจารย์: หัวข้อ **"การประยุกต์ใช้ปัญญาประดิษฐ์ (Generative AI) ในการพัฒนาเว็บแอปพลิเคชันฉบับสมบูรณ์"**

---

## 🌟 1. ข้อมูลภาพรวมของโปรเจกต์ (Project Overview)
**TravelThai** คือแพลตฟอร์มท่องเที่ยวไทยเวอร์ชันสมบูรณ์ (Complete Web Application) ที่ได้รับการวางระบบ ออกแบบสถาปัตยกรรม และเขียนโค้ดด้วย **Generative AI** 100% ตัวเว็บรวบรวมสถานที่ท่องเที่ยวสำคัญ 16 พิกัด ครอบคลุม 4 ภูมิภาคหลักของไทย พร้อมระบบอัจฉริยะเชิงโต้ตอบ (Interactive Features) ครบถ้วน เพื่อเป็นตัวอย่างชิ้นงานระดับ A+ สำหรับการส่งงานอาจารย์

---

## 🚀 2. ฟังก์ชันเด่นที่พัฒนาอย่างสมบูรณ์ (Complete Features)

1. **ระบบจัดแผนการเดินทางอัจฉริยะด้วย AI (AI Itinerary Generator):**
   - ผู้ใช้เลือกภูมิภาค, จำนวนวัน (1-3 วัน), และสไตล์การเที่ยว
   - AI สร้างแผนเที่ยวแบบเจาะลึก รายวัน (เช้า / บ่าย / เย็น) พร้อมปุ่มคัดลอกแผนการเดินทางลงคลิปบอร์ด

2. **ระบบค้นหาและคัดกรองข้อมูลแบบ Multi-Dimension (Search, Filter & Sort):**
   - คัดกรอง 5 หมวดหมู่: ภูเขา & ธรรมชาติ, ทะเล & เกาะ, ประวัติศาสตร์ & วัด, วิถีเมือง & คาเฟ่, แอดเวนเจอร์ & เดินป่า
   - คัดกรองตามภูมิภาค (เหนือ, ใต้, กลาง, อีสาน, ตะวันออก)
   - จัดเรียงผลลัพธ์ตาม: แนะนำ (Featured), คะแนนรีวิวสูงสุด (Top Rated), หรือชื่อตัวอักษร (ก-ฮ)

3. **ระบบประมาณการงบประมาณท่องเที่ยว (Trip Budget Estimator):**
   - คำนวณแบบจำลองค่าใช้จ่ายตามจำนวนวัน ผู้เดินทาง และสไตล์การเที่ยว (สายประหยัด, สายมาตรฐาน, สายพรีเมียม)
   - จำแนกค่าที่พัก ค่าอาหาร และค่าเดินทาง พร้อมปุ่มสั่งพิมพ์/บันทึกสรุปงบประมาณ

4. **ระบบสภาพอากาศและข้อแนะนำการแต่งกายแบบเรียลไทม์ (Live Weather Simulation):**
   - แสดงอุณหภูมิ สภาพอากาศ และข้อแนะนำการเตรียมสัมภาระแยกตามแต่ละภูมิภาค

5. **ระบบคอมมูนิตี้และเขียนรีวิว (Traveler Reviews System):**
   - มีระบบรีวิวพร้อมคะแนนดาว (Star Rating) และแบบฟอร์มให้ผู้ใช้โพสต์รีวิวของตนเอง โดยบันทึกลงใน `localStorage` ทันที

6. **ระบบบันทึกรายการโปรด (Wishlist with LocalStorage):**
   - กดปุ่มหัวใจที่การ์ดเพื่อเก็บสถานที่ที่ชอบ ดูรายการโปรดผ่านป๊อปอัป ข้อมูลคงอยู่แม้รีเฟรชหน้าเว็บ

7. **ระบบ Dark Mode / Light Mode:**
   - สลับโหมดกลางวัน/กลางคืนได้อย่างนุ่มนวล พร้อมจดจำค่าที่ผู้ใช้เลือกไว้

8. **ระบบการแจ้งเตือนแบบ Toast Notifications:**
   - แจ้งเตือนสถานะเมื่อบันทึกรายการโปรด คัดลอกตาราง หรือส่งฟอร์มอย่างสวยงาม

## 💻 3. เทคโนโลยีที่ใช้ (Tech Stack)
* **HTML5 Semantic Elements:** โครงสร้างเว็บมาตรฐาน SEO เป็นมิตรต่อ Accessibility
* **Tailwind CSS (CDN) + Dark Mode:** จัดการดีไซน์ทันสมัย Responsive ทุกหน้าจอ
* **Modern JavaScript (ES6+ Vanilla):** ไม่มี Dependency ภายนอกที่ซับซ้อน โหลดเร็ว ใช้งานได้ทันที
* **Lucide Icons:** ชุดไอคอนเวกเตอร์ระดับพรีเมียม
* **Web APIs:** LocalStorage API, Clipboard API, Print API

## 🤖 6. บันทึกกระบวนการทำงานร่วมกับ AI (สำหรับอธิบายให้อาจารย์ฟัง)
* **Prompt Architecture:** ใช้การ Prompt ระบุ Component และโครงสร้างข้อมูลแบบแยกส่วน (Data separation)
* **Algorithmic Prompting:** สั่งให้ AI เขียน Logic คำนวณงบประมาณแบบมีตัวแปร Multiplier ตามภูมิภาค
* **Design Systems:** กำหนด Palette โทนสีธรรมชาติ ท้องฟ้า และ Dark Mode เพื่อความสบายตาในการใช้งาน
